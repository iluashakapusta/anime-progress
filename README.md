# Аниме-прогресс (веб)

Неофициальное веб-приложение: показывает, на каком сезоне, серии и минуте вы остановились в каждом аниме, по истории просмотров вашего аккаунта [AniLiberty](https://aniliberty.top). На iPhone его можно добавить на экран «Домой» (Safari → «Поделиться» → «На экран "Домой"»), и оно будет открываться как приложение.

Это статический сайт без сборки и сервера: `index.html`, `app.js`, `sw.js`, `manifest.webmanifest` и иконки. Браузер обращается к API AniLiberty напрямую (API разрешает запросы с любых сайтов). Ключ сессии и кеш хранятся в `localStorage` браузера.

## Публикация на GitHub Pages

Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.

## Локальный запуск

```bash
python3 -m http.server 8000   # http://localhost:8000
```
